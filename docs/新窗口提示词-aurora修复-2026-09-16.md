### P0 — 立即执行（恢复可用性）

1. **换掉失效的分析模型**

   实测依据：`gpt-5.5` 在「无 response_format / json_object / json_schema」三种模式下**全部返回 502**，而 luna 和 sol 全绿（含视觉输入 + strict schema）。

2. **修格式校验器硬编码（1 行）**
   `backend/app/xinghe_agent.py:5612`
   ```python

   if image_format != "JPEG":
   # 改成：
   if image_format != IMAGE_FORMAT.upper():
   ```
   原因：`IMAGE_FORMAT = "png"`（同文件 :163），但校验器仍要求 JPEG。上一个提交 `0b5ca7e` 只改了请求格式、没改校验器，**修复是无效的**。
   → 见文档 **RC-2**

3. **恢复重试机制（2 行）**
   `backend/app/aurora_main_image_provider.py:1509` 的 `_v20_gateway_error()` 里加：
   ```python
   error.http_status = getattr(result, "http_status", None)
   ```
   `backend/app/aurora_main_image_planner.py:58` 的 `AuroraPlanningError` 里加：
   ```python
   http_status: int | None = None
   ```
   原因：异常没带 `http_status`，导致 `_classify_transient_failure()` 把上游 502/429 判为**不可重试**，生产已配置的 `POLARIS_AURORA_MAX_TRANSIENT_RETRIES=2` 完全没生效。
   → 见文档 **RC-6**
