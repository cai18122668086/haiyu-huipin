# 海宇绘品手机号账号接入

本次仅实现本产品的手机号账号。复用海宇数科的腾讯云短信应用、签名与模板，不调用海宇账号接口，不共享账号、钱包或积分。支付未接入。

## 当前项目集成状态

手机号账号增量现已合入 `polaris-commerce-next`，并在修改前备份了受影响文件。保留原有 Provider 配置、复刻修复、页面修改、实际 `.env` 和 `.env.local`；现有生成服务未重启。一键复刻排查目录和数据未改动。

公开页面包括首页、工具目录、帮助中心、灵感专区及协议页面。游客点击具体创作功能时，在当前页面显示登录弹窗；关闭后继续浏览。注册和找回密码在弹窗内切换，登录成功进入原来选择的功能。直接访问功能地址也须登录。账户、素材、记录、个人控制台和后台仍受鉴权保护。公开页面在确认登录后才加载工作区、个人信息和内部运行状态。

新增迁移已在当前预览数据库的只读备份上验证，33 张表的行数全部保持，数据库完整性检查通过；未对运行中的数据库执行迁移。正式启用当前项目新服务前仍需按既有发布流程执行 `20261027_0028`，不能直接重启旧数据库上的 API。当前手机号演示仍使用独立的 18931–18934 服务。

当前项目通过 43 项后端检查、19 项前端认证回归和 22 项真实 Core/Redis 链路断言。测试使用临时数据和模拟短信，没有再次向用户发送短信。

## 产品流程

- `/auth/login`：验证码登录、手机号密码登录；纯手机号界面。
- `/auth/register`：手机号、验证码、密码、确认密码；须主动同意用户协议和隐私政策。
- `/auth/forgot-password`：短信验证后设置新密码。
- `/account`：手机号脱敏展示、密码状态、校验当前密码后修改；修改后重新登录。
- 登录卡片在视口中水平、垂直居中；高度超出小屏时保留页面滚动。

验证码生成、错误次数限制和一次性核销由本项目自己的 SuperTokens Core 处理。后端额外将短信验证码有效期限制为 5 分钟，使用 Redis 原子限制同一手机号 60 秒间隔、24 小时 20 次、同 IP 一小时 40 次。密码登录另有手机号/IP 限流及同源校验。Redis 不可用时禁止发送或密码登录。Redis 前缀为 `polaris:auth:`。

密码仅保存在本产品 `users.password_hash`，使用带随机盐的 scrypt，不上传短信平台。`password_version` 在重置或修改密码时递增，业务鉴权拒绝旧版本会话；同时撤销 Core 的旧会话。手机号对应独立本地用户及个人工作区。

## 配置与集成

1. 安装后端依赖；新增腾讯云官方短信 SDK `tencentcloud-sdk-python-sms==3.1.153`。配置导入脚本使用开发依赖 PyYAML。
2. 停写并备份目标数据库后，按项目发布流程执行 Alembic `20261027_0028`，增加手机号、密码哈希、密码版本与手机号唯一索引。本次未对原项目或线上数据库执行迁移。
3. 只读现有海宇配置：`python scripts/configure_haiyu_sms.py --source <海宇 platform.production.yaml 绝对路径> --target <本产品 backend/.env.sms.local 绝对路径>`。脚本拒绝覆盖，输出不包含凭据。该文件已被现有 `.env*` 规则忽略。
4. 本地后端从 backend 工作目录读取 `.env` 和 `.env.sms.local`。容器部署需将对应 `POLARIS_AUTH_SMS_*` 值放入服务端私密环境文件；生产 Compose 已补充传递。短信启用后不再要求 SMTP，邮箱密码认证接口不启用。
5. Core、数据库和 Redis 必须继续使用电商生图自己的实例/数据。生产保持 HTTPS、Secure Cookie 与现有会话刷新/CSRF 防护；不要使用预览配置替代生产配置。

新增业务接口：`POST /api/v1/auth/phone/password/login`、`GET /api/v1/auth/phone/profile`、`POST /api/v1/auth/phone/password/change`。OTP 使用 SuperTokens Passwordless 端点，消费验证码时传入用途和注册/重置密码。
