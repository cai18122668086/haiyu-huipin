# 前端界面改版规范

## 视觉方向

本轮采用“电商出图工作台”方向：借鉴焦点 AI 的黑色顶栏、浅色画布、扁平导航、
单一高识别度强调色和图片优先布局，但不复制其品牌黄色与固定宽度问题。

核心配色：

- 顶栏：`#1E1E1E`
- 主操作：`#F26343`
- 主操作悬停：`#D74B2E`
- 柔和强调：`#FFF0EA`
- 页面背景：`#F7F6F3`
- 卡片与工作区：`#FFFFFF`
- 边框：`#E6E3DE`
- 正文：`#1B1B1B`

## 结构原则

- 首页采用与参考站一致的层级：品牌横幅、两张主入口、三张品类卡和底部对话式入口。
- 管理页保留功能导航；两类工作台的左栏改为“新建创作 + 最近记录 + 素材/记录入口”。
- 顶栏保持平直、紧凑，使用橙色下划线表示当前页面。
- 卡片减少蓝紫渐变、发光和大面积彩色底，主要依赖商品图片与留白。
- 工作台保留现有画布、任务阶段、参数、助手、结果和断点续作能力。

## 边界

- 不修改 `/api/v1`。
- 不修改生产数据模型、金额/额度格式与对象存储边界。
- 不增加任务状态；继续使用
  `draft / queued / planning / processing / partial / completed / failed / cancelled`。
- 商品详情图仍需先确认页面规划，再进入生成。
- 当前继续使用 mock data，界面确认后再逐页接入真实 API。

## 响应式

- 桌面端：以浏览器 100% 缩放为设计基准；首页参照焦点 AI 使用约 64vw 的等比内容区（最高 1224px），卡片宽高随视口同步缩放，避免只横向拉伸；管理页和工作台控件按原基线约 150% 放大。
- 平板与窄预览窗：首页继续保持“2 张主入口 + 3 张品类卡”；侧栏转抽屉，助手区移到主内容下方。
- 手机端（480px 及以下）：页面单列，筛选与步骤允许内部横向滚动，但禁止页面级横向溢出。
