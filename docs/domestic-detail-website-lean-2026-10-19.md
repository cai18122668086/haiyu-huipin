# 国内详情网站精简合同 WEBSITE_LEAN_V1

国内详情页面通过 `website_contract_version=WEBSITE_LEAN_V1` 选择网站合同，后端参数、OpenAPI 与前端类型保持一致。未带标记的原有请求继续使用原合同。此变更不重做 Worker 路由，不修改国内主图或生产服务。

## 规划

模型只创作一份 `claim_coverage` 主卖点任务映射，每项包含实际事实 ID、证据边界、屏幕任务和简短理由。程序从同一来源产生深度与回顾视图；原生编译器再次检查映射一致性、独立证明、使用判断、回顾及事实边界。不能猜测事实映射、添加模型未创作的任务，或覆盖显式冲突。

全局故事与双屏细节仍分阶段完成。每阶段只加载相关参考规则；双屏只接收相关 Pair 合同，省去重复商品资料和已验证的并行账表。完整紧凑故事、商品身份、证据、系列风格与当前接缝仍保留。

出镜角色和四项视觉签名只创作一次。重复策略和表达签名允许省略，由程序精确投影。显式错误或空值不会被默认值覆盖。稀疏纠错及已知回复恢复在合并后再次运行同一投影；结构纠错仍全局最多一次，未知请求不重发。

## 像素检查

网站合同由审批方案、每屏合同及签名生成请求共同绑定。审批文档明确说明采用六类核心检查；旧任务和独立 Skill 的原有检查保持原样。

每屏检查从 44 项缩为六类：

1. 商品身份是否与原图一致。
2. 事实与销售文案是否有依据。
3. 关键文字是否正确、可读。
4. 已批准职责、卖点和内容是否实际出现。
5. 构图、结构与连续性是否出现实质问题。
6. 视觉证明是否真实、没有伪造。

每类必须有具体可见证据；保留实际 OCR、商品出镜范围、已出现及遗漏内容、可见证明关系、品牌范围和身份比较。每屏必填观察由 62 项降为 12 项，不再要求标题排名、景深层数、主体占比和重复审美评分。失败行只需核心检查名及可见证据，统一修复诊断再集中填写原因和修改策略。

两屏仍在同一次 Pair 审查中检查顺序、职责、信息增量、文字绑定和实际接缝。真实商品变形、编造事实、关键字不可读、卖点缺失、误导性证明及破坏内容的接缝仍是实质失败。轻微装饰、间距及主观评分不触发机械返工。未知观察或互相矛盾的 PASS 会停止，不能换取新的生图机会。

一对画布仍只有首次生成和最多一次自动修复。第二次仍有实质问题时保留原始观察和残差，继续后面的 Pair。尺寸、固定切片、原始图片与审查回执、实际文件字节和最终交付绑定仍由原生运行时验证。整页深度复审保持可选。

## 验证边界

原生 Skill 保持 v4.3.1，新增独立的 WEBSITE_LEAN_V1 合同与来源指纹，避免把历史结果改写成新合同通过。独立 Skill 与不带标记的请求保持原检查；新合同的像素结果使用独立 Schema。

静态检查、117 个后端文件的 mypy、前端类型检查及 Skill 验证器通过。74 项聚焦回归全部通过，覆盖新合同完整规划、四对合成成图和持久化交付，缺项、未知观察、矛盾 PASS、一次修复后残差，以及原有 bounded authoring 和出镜策略。合成用例始终标明 SYNTHETIC，不能作为真实像素质量证明。

审计 Schema 从 57,731 字节降为 22,857 字节，约减少 60%。首批双屏系统参考规则从 36,040 字符降为 16,641 字符，普通请求文本约减少 20%；这不是供应商 token、费用或真实等待时间的测量。真实鞋子测试单独保存请求、回复、费用与图片验收结果，不能用 CI 或合成回归代替。

用户本轮明确授权使用三张原图模拟真实用户提交，并确认“不限制额度”。该授权允许这一轮受控测试，不增加结构纠错、图像修复次数，不授权自动创建后继任务，也不自动合并或部署。

## 网站直接编译 WEBSITE_DIRECT_V2

网站默认改为 `WEBSITE_DIRECT_V2`。借鉴主图“锁定商品后本地编译”的方式，模型只做一次商品识别和一次整页创意简案；不再创作痛点、公式结构、主卖点深度、回顾及多套覆盖账表，也不再四轮逐对补全。简案只包含五项视觉风格、每屏职责/文案/事实引用/画面/构图/镜头/商品出镜，以及每对的可见转场。

原始 user facts 在整套至少展示一次，照片观察可以作为支持证据，不强制成为独立主卖点。编译器只根据这份简案和原始事实生成运行时字段；未知事实、丢失用户卖点、篡改简案显示视图仍会被拒绝。产品身份、品牌范围、固定尺寸、审批绑定、原始请求结果和一次自动修复保持不变。像素检查继续复用六类 `WEBSITE_LEAN_V1` 审查合同。

新模式的网站流程保留完整方案确认、逐对连续生成、八/十/十二屏切片、最终审阅和下载。额外整页模型评估、自动交付授权和局部任务分叉不进入新模式首版流程；历史任务仍显示原有工具。真实整页检查由实际查看整套图片完成，不能用合同或合成结果代替。

新增完整路径用例验证两次规划调用、原生审批、四对持久化、八屏、最终确认与下载包；只补充未知事实及遗漏用户卖点的两个关键拒绝条件。真实供应商验收另存原始回执，不因一轮失败结束总目标。
