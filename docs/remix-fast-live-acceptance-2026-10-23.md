## 实际发现和修复

旧实现只要求分析模型返回 JSON 对象，没有规定字段类型。真实分析将 `identity_constraints` 返回为数组，接入层要求字符串，导致生图前合同校验失败。离线夹具一直返回字符串，因此没有暴露这个问题。

修复为准备与快检两阶段各自的 JSON Schema，完整列明必填字段、字符串、数组和布尔值类型；准备上下文同时传入原生 `ratio` 计算出的画布，避免模型把参考原图尺寸当作输出尺寸。仍执行本地字段校验，不会将不合规响应强转成通过。上游请求编号、错误码和 HTTP 状态进入分阶段用量记录，分析不可用与像素快检失败采用不同提示。
