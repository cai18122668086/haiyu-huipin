# 国内详情请求前的连接恢复

隔离验收与只读供应商探测实际复现 TLS SSLEOFError。旧传输把连接建立与付费 POST
合成一个步骤；中断后必须保留未知结果，不能盲目重发整个规划或生图请求。

国内详情现在单独选择原生传输：只在 HTTPS connect 阶段最多尝试五次，并限制连接
超时预算。这个阶段尚未向供应商发送 HTTP 头或正文；经过代理时仅先建立 CONNECT
隧道和标准证书校验的 TLS 连接。连接在 HTTP 请求状态开始前建立，代理 CONNECT 失败时可安全关闭套接字，不会重置已开始的 POST。

握手成功后，原始幂等键、JSON 或 multipart 正文只发送一次。HTTP 错误、返回内容
错误、已发送正文后的断连不触发重发；原有未知结果日志与恢复边界继续生效。
拒绝重定向，证书错误立即失败，不降低证书或主机名校验。网络握手不算新的生成尝试。

国内主图及其他功能保留原传输。注入的测试、供应商 transport 也保持原路径。
旧任务继续由冻结 API 处理，不因这次连接恢复自动重跑。

离线测试使用真实 http.client 写入流程验证握手失败后仍仅提交一次正文，覆盖
证书失败、重定向、HTTP 429/500、发送后断连，以及主图和详情的分支隔离。
