1. Explicit processing choices
The registration/SMS login form separately presents Hong Kong processing and AI
training notices, unchecked by default. The same versioned notice JSON is used by
frontend and backend. The registration flow validates choices before SMS/OTP;
SMS auto-registration validates again after phone proof and before provisioning
the application account. Existing users can sign in to read/download without
regranting withdrawn AI training. Password recovery also remains available
without granting AI training. Authenticated users may accept or withdraw through
account settings. Reads, downloads and cancellation remain available; new workspace
writes require the current recorded choice. Existing accepted background jobs retain
their submission authority and are not automatically cancelled by withdrawal.

Additive Alembic migration 20261030_0037 creates processing_consents. It does not
assume consent for existing users or alter their wallets, credentials or jobs.
Records contain purpose choices, policy version, notice hash/snapshot, source and
acceptance/withdrawal timestamps. Reacceptance preserves the previous receipt.
This implements the site's existing declared processing policy; it does not change
the provider's actual processing or training behavior.

3. Display images
build/generate-display-images.py creates content-addressed WebP display derivatives
and lib/display-images.json. Run it using the project's Pillow environment when
approved public example art changes. Original source/delivery files remain intact;
the frontend maps only registered public showcase art. User images, task outputs
and download URLs do not pass through this derivative map. srcset/sizes allow
smaller views to select smaller files. Display hashes are immutable-cache safe.
The largest variants of logo plus three hero images total 295356 bytes, compared
with 6157812 bytes for their previous originals (95.2% fewer bytes). Actual network
selection depends on viewport and device pixel ratio; no new LCP claim is made.

4. Compact account navigation
At widths up to 960px, the account trigger is a fixed-width named icon; full
membership and balance remain in its popover. Small-screen navigation spacing is
adjusted. Local synthetic balance 999999999 is used for UI verification only.
