# 国内详情原生像素链路（本地候选，2026-10-17）

## C2 已完成的技术范围

供应商原图、规范化后的双屏画布及两张固定切片现在有独立的文件 SHA-256、RGB 像素 SHA-256 和来源关系。原生 Harness 在写入像素审核前重新执行既定规范化算法作内存比对，并逐张核验固定窗口实际像素。仅尺寸相同不能通过。网站重新读取这些原生文件，核验路径、传输证明、字节、像素、坐标及顺序，再把原生画布交给审核、把原生切片作为候选输出保存；不再另行编码或缩放切片。

原图复制到会话内不可覆盖的 provider-originals，原供应商调用的 .artifact 与成功凭据保持原哈希。EXACT 模式保留原 RGB 编码；EXIF 方向、颜色通道或多帧需要转换时，实际保存 PNG 派生画布。非目标尺寸按既有 Skill 规则等比处理，记录裁切、扩边与原始编码尺寸，不拉伸。审核和恢复都检查原图到画布的确定关系。

每次签名请求另存到不可覆盖的 signed-requests，并在原生账本记录实际文件指纹。面向调用方的当前 generation 文件可在修复时更新，首次请求文件与首次原图继续保留。新只读命令 inspect-pair-artifacts 可检查 LATEST_RECORDED 或 ACCEPTED；后者还要求与原审核封存的链路哈希一致。

已接受结果的恢复必须同时满足原生文件链路、供应商成功回执和原响应 .artifact。存储画布与原生画布必须逐字节相同，候选单屏直接复用原生切片。不会用规范化 SHA 替换原始付费响应 SHA。
