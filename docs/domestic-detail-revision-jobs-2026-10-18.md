# 国内详情独立修订子任务构造（本地候选）

父提交 `7d01c5d46d5cb9fa2c7f32dd2a4b03cfc795bc93` 已保存只读报价与精确授权。本候选实现独立子任务构造函数、来源冲突守卫及新任务的费用预留，暂不开放执行 HTTP 入口。原生分支、执行前语义范围核验、逐双屏来源绑定、实际局部变化审核、恢复和界面仍需继续接入。

子任务构造先取得公共工作区配额锁，再从当前来源与实际账户路由重新计算报价，核对当前用户、工作区、来源与精确确认文本。旧报价、另一用户和泛化的继续均在插入前拒绝。相同根任务已有运行中修订、结果未知的公开 attempt/item、无原始回复的模型请求或未核对的图片请求时，先核对原请求，不能另开付费周期。

新任务仍使用 DETAIL_PACK，拥有独立任务、方案、审批回执、费用预留和原生意图。目标相邻双屏为 pending，其余 6/8/10 屏只建立已核验资产的复用关系；图片字节不复制、不改写。不会把原最终 ZIP 作为新交付。原输入、锁定身份和事实、原方案、原编译审批及原审批回执保留来源记录；原自动交付授权从新任务有效回执移除，新任务固定等待人工最终审阅。

公共执行器继续管理提交事务、outbox、租约、取消、幂等和计费。当前内部构造函数不自行提交、不写 outbox、不调用模型或图片；待所有执行守卫完成才连接公开入口。通用 retry/clone 对此类独立修订拒绝，避免绕过新授权或复制结果未知的请求。

为后续单次自然语言范围核验，报价明确增加一次模型预检：最多一次范围预检、四次像素/身份审核、两次图片请求，共七次供应商请求。最高费用为两次图片单价加五次模型单价；源码和策略指纹变化使旧报价失效。公共额度记录的 planner_reserve_micros 是每次模型请求的单价，不能把五次模型总额写进去；测试使用现有账本计费函数检查五条未报告费用的模型记录恰好按五次单价结算，并留出两次图片的预算。
