# 签到积分按领取时会员状态确定有效期

普通用户每次签到仍领取10积分，新发放批次自到账起24小时有效。个人账户有已生效、未到期且未取消的会员时，新签到批次保留30天。每日领取次数仍按北京时间自然日计算，24小时不等于午夜清零。

只改变新签到批次的到期时间，不迁移或重算已有积分。领取后购买、到期或取消会员不会改变该批次的到期时间；重复签到仍返回原记录。邀请奖励的30天有效期、免费快速复刻权益不变；同时发布的商品调价详见 `red-gold-promotions-20261109.md`。

奖励接口保留原validity_days字段作为邀请奖励期限，新增checkin_validity_hours表示当前可领取签到的期限，checkin_expires_at返回今日已领取批次的真实到期时间。签到导航和福利页据此显示期限，已领取时优先展示该批次的实际到期时间，避免历史30天积分被误显示为24小时。

覆盖普通用户、有效会员、到期、未生效、取消、其他工作区会员、领取后升级与取消、历史批次不变、24小时过期边界和北京时间跨日重复领取。2026-11-09已随红金活动发布，无数据库迁移和历史积分更新脚本。
