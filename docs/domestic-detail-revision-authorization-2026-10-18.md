# 国内详情局部修订报价与独立授权（本地候选）

父提交 `e2afbc73837a53e1052309e3a2b9171522fb1543` 已实现原生独立修订分支和实际编辑底图。本候选新增只读报价接口与精确授权构造；独立网页修订任务、配额、执行及界面继续在后续步骤接入。

`POST /api/v1/workspaces/{workspace_id}/jobs/{job_id}/local-revision/quote` 从当前用户有写权限的工作区取原任务，仅接受已具备冻结最终审阅材料的国内详情任务。接口通过原生来源校验，不相信客户端提供的原图、价格或审批内容。原方案与批准的 8/10/12 屏顺序、选中相邻双屏、原画布及切片像素谱系、原始会话字节、来源生成绑定、审批材料、Skill 和运行源码均进入报价指纹。原质量残差完整保留。

请求保留用户修改原文及修改、保留、不得退化三组要求。五项全局变更标志必须显式填写布尔 false；缺失、0、字符串 false、额外字段、泛化的继续或重试均不构成授权。此类型校验不能证明自然语言确属局部变更；执行前仍需核验它与已锁定身份、事实、目标受众、风格和屏幕顺序相容。不得静默改写用户要求。

报价绑定当前实际图片账户路由和审核模型路由的指纹、当前单价及价格版本，不输出密钥。当前报价上限为两次图片请求与四次像素/身份审核模型请求，最高费用为两次图片单价加四次审核预留。结果未知仍占原请求槽位。报价不创建任务，不保留额度，不写 outbox，不调用模型或图片供应商。后续若增加单次语义范围预检，必须先明确扩展报价和费用并重新确认，不能花费未报价的额外调用。

授权帮助函数只接受服务端从当前来源重新计算的完整报价，并逐项核对来源任务、工作区、当前用户、源码、请求策略及精确确认原文。报价和请求 DTO 源码另有策略哈希，类型或局部边界变化会使旧确认失效。来源原本的自动交付授权仅作为原审批记录的哈希保存；新修订固定等待人工最终审阅。

本候选没有开放执行入口。后续必须在精确确认后新建独立 DETAIL_PACK 子任务，仅目标双屏待生成，其余屏幕复用已核验产物；新费用、队列、取消、租约和幂等仍归公共执行器。修订双屏与复用双屏须各自核对新旧生成绑定。实际前后像素观察需覆盖用户局部要求及另一屏保留义务，不能把原计划文案当作观察。中断恢复只核验原签名请求和已保存原回复，不以新周期补发。

离线验证：24 项类型、来源、授权、路由与价格边界通过；两项实际 API 链分别从人工确认来源和原自动交付来源报价，数据库全表快照（含配额、账本、审计、outbox）、原任务全目录及调用次数保持原样。改价与原会话字节改变使报价指纹失效；无效范围和旧审阅材料拒绝。两条链的生成绑定均为当前源码。mypy 105 个源码文件、Ruff、TypeScript noEmit 通过。
