## 幂等、恢复与账单

方案绑定全部六张职责、主商品列表、原图 SHA/尺寸、Skill 哈希与当前完整方案哈希。
规划预处理 `preparing` 与实际请求 `invoked` 分开持久化，重复规划 worker 不使原任务失败，
未知付费结果停止重复提交。成功规划与有限回执在同一事务提交，避免回执已保存但方案缺失
的成功写入窗口。没有完整已确认方案的失败任务不能排队重试，API明确提示核对后新建。

生图前持久化逐张回执；未知提交/下载状态禁止重发。先保存原图，再交给公共执行器发布素材。
失败项重试保留成功页、复用确认方案；已有原图且最终发布失败时新增生图调用为零。
回执还校验来源任务必须是本任务或真实重试祖先、存储路径归属和字节 SHA。
冻结生成哈希忽略通用重试改写的 state/cost/usage/metrics，但包含完整提示词涉及的所有字段。
用户明确 clone 时保留冻结方案并使用新调用身份清空旧图片回执；未知源调用不允许 clone。

快速模式预留一次规划加六张图，重试只预留待执行图片数且不再规划。
独立 quota ledger 分支将真实规划纳入七次调用；无方案的失败/截断/未知规划按回执保守记账，
未付费的源素材/Skill预处理失败为零。原版记账不变。积分仍按正常成功图片结算，
内部预算估算不冒充上游实际成本；上游未报告实际费用时 actual 为 null。
私有回执从公共 job configuration 过滤。
