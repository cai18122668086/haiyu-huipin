## 图案与文字

适用的换背景、白底、参考混剪、主图和亚马逊画面使用独立背景板与原图商品图层。分割模型只预测 alpha；图层 RGB 与原始照片的对应区域逐字节核对，保存来源图片、裁剪区域、图层、背景和合成结果的 SHA256。允许的商品变换是保持比例的缩放与平移。换色、换模特、试穿和姿势迁移不采用这条路径，避免撤销用户明确要求的修改。

先检查供应商背景原图的实际尺寸、比例、最低尺寸和透明度，再进行商品合成；无合格原生背景时禁止补边、改画布或重采样来通过门禁。背景原图保留为私有证据。最终图片明确属于原始商品像素合成图，不能宣称其字节是未经修改的供应商完整原图。

U-2-Net ONNX 在镜像构建时从固定公开来源下载并校验 SHA256；运行时不下载模型。NumPy 和 OpenCV 使用带哈希的依赖锁文件，许可随源码保留。每个工作进程串行使用一个模型，通常执行两次局部推理；歧义时至多追加一次保留完整选择区域的上下文调整，歧义阈值不改变。原图与抠图配对进行完整性审核，任一未解决缺陷均阻断生图。

空间选择采用完整原图清单和明确的对象 ID。服务端验证所选 ID 确为用户指定的下排、上排或左右子集，再从清单构造唯一记录，避免规划器复制整段对象记录时改写坐标或文字。营销画面由原批准方案决定每屏商品与文案；屏内坐标经过边界、重叠和双屏接缝校验，不把原图裁剪坐标用于输出布局。

细小反光五金可在原始轮廓附近进行受限的源像素边缘细化。若首次抠图审核仍发现小缺陷，只允许一次有坐标、面积和区域限制的 alpha 修正，然后以新哈希重新审核实际像素；不得重复审核同一失败图以碰运气。删除背景仅限未印刷的顶部五金区域，不能删除人物、图案或文字。修正后的四项抠图条件与最终全部保真条件仍须通过。混剪先量测所选原商品的实际可见比例，再生成统一缩放可满足的规划。

同一任务、同一来源字节、选择和模型版本对应的抠图只验收一次，并复用完全相同的已验收像素；失败的相同抠图也保留失败标记，不能换一个套图条目反复审核。每张最终图片仍执行全部原有校验。营销背景指令明确要求渲染批准的标题和说明，空背景仅指不绘制商品，不能导致已批准文案丢失。

分割上下文按原图商品清单中的空间单元收紧，避免白底中间图的相邻商品进入推理裁剪。原有 95% 连通性阈值同时用于首次分割与最终边缘细化，不能在合并遮罩后重新引入碎片。原生详情中明确批准的微距模块可以从已验收完整图层裁取原像素细节；整枚商品模块仍要求完整主体，所有裁剪窗口均在购图前验证并冻结。

明确要求把金色五金改为银色时，候选路径可定位原照片中的金属扣、环与连接件，在有界金色掩膜内保留明度进行银色转换。每块区域和总修改面积均有限制，其他像素与原图逐字节不变；不为此购买重绘图片。其他目标颜色、材质或修改仍采用既有编辑路径。该路径仍执行六项视觉保真审核和独立文字转录。

批准的营销标题与说明采用固定 Noto Sans CJK SC 字体渲染，不能交给背景生成器重新拼写。每段批准文案必须有唯一文字框；文字框不能相互重叠、覆盖商品或跨越双屏接缝，并须能以可读字号完整排入。布局无效时最多修正一次规划，再次失败即停止购图。字体固定来源提交、SHA256 和 OFL 许可，只在镜像构建时下载。供应商背景仍先通过原生画幅门禁，商品和文字合成不改变其画布尺寸。

## 回执与审核

派发生图前冻结来源哈希、选择、图层、背景描述、布局和实际传输提示词。原生详情子调用必须对应已授权的父工作区、任务、条目、尝试及精确签名 token；批准方案、逻辑幂等键和原生调用栅栏保持。不同子调用的私有证据分别绑定，不能覆盖同一尝试中的另一张图片。

六项保真审核和各功能原有审核均保留。参考混剪另提供经冻结来源绑定的原图放大区域，避免把原图已有特征或反光误判成新增内容。缺字段和无效合同记录字段路径、检查名称和次数，不向运行日志写入原始图片、提示词或凭据。历史缓存图片也必须进行来源与文字审核；不能以复用为由跳过验收。

保真审核和混剪提供同一缩放比例的原商品与实际候选区域并排证据，完整候选图仍供构图、水印及来源泄漏检查。构造证据前额外核对不透明商品像素，出现任何差异即失败。来源识别、独立文字转录、局部五金选择、抠图审核、背景布局和混剪细节审核支持显式配置 `POLARIS_IMAGE_FIDELITY_PRECISION_MODEL`；一般业务规划保持原模型路由。Kimi 的保真调用使用兼容 JSON 对象传输，完整 schema 留在原请求并执行原有本地校验；来源、OCR、抠图和布局关闭扩展思考并限制输出，避免全部额度耗于思考而没有最终 JSON。模型返回的失败条件不得由服务端改写为通过。

未知供应商结果继续查询原任务，不能新建替代订单或切换模型重复购买。质量拒绝保留私有候选并记录原有费用；规划与审核费用一并汇总，会员结算仍按既有交付规则执行。

详情素材分析的明确截断回复加入既有两次修正上限，与字段、参考覆盖错误共用次数。新调用须保留相同来源、模型与完整校验，并保存独立回执和所有费用。原回复未完成、被篡改或与修正父回执不符时继续阻止派发。

## 发布边界

原始客户图片、输入、环境文件、供应商凭据和验收产物只保留在受限测试目录，不进入仓库。真实验收使用独立数据库、存储和操作员预算，不扣客户积分。

上游原生尺寸支持已经取得用户明确扩展授权。尺寸与质量参数透传的候选代码仍需与实际上线基线逐项合并核对。只有完成真实原图验收的供应商绑定和尺寸可以加入生产白名单；不能据此扩大其他通道能力。生产发布前备份配置与数据库，保留回滚镜像，并再次检查最新任务和活动调用。

背景布局规划同时看到每个独立商品的原图层与实际宽高比，不能把同一个整组商品框重复用于各成员。重叠错误反馈明确指出冲突条目与坐标，原有不重叠、边界、字号及文字保真条件保持。CI 浏览器使用 Chromium 实际发布的 DevToolsActivePort，避免预约端口释放后的竞争；启动期限与页面断言保持，并保留有界标准错误用于定位故障。

来源的不可读标记必须单独写为 `UNREADABLE`，不能混入中文说明并冒充实际印字。违反完整 schema 时最多一次原来源修正，失败后在相同来源范围保留失败标记；不重复购图。抠图和背景字段错误日志记录实际 profile 与字段路径。

规划获知原照片可支持的完整商品、原细节裁剪及统一缩放能力，不能自行承诺未拍摄的开扣、拆件或新视角。背景指令保留已批准的手、包、挂点与承托面，携带根据原图层和冻结单元格量测的实际商品位置；禁止生成商品不能误删必要场景。最终成品仍须证明真实挂接、承托、文案和细节，不能用生成回执代替验收。

抠图审核把同一比例的实际原照片区域与实际遮罩预览并排提供，保留完整原照片作为权威。坐标修正仍按右侧预览自身计算，不能把定位矩形直接填为前景；恢复仅限与现有扣具相连的原照片金属像素，不能擦除金属或改写印刷。混剪先验收该遮罩再据此规划比例。

局部五金换色在来源阶段定位完整印刷面，例如含全部文字列、副列和版权行的整个吊牌，不能切掉边缘字形。区域必须为来源商品内互不重叠的凸四边形；倾斜印刷面的外接矩形交叠不代表实际区域交叠。独立读字器只收到实际原像素的最近邻放大区域，无答案文字。来源与候选使用同一几何，每列文字仍独立读取，重复实体上的相同字样仍逐件计数，任何原有匹配条件都不删除。换色掩膜另禁止覆盖这些印字区域。

最终原图对照使用最初冻结的请求与来源绑定，不能用已投影的背景提示词重新匹配冻结回执。对照失败时仍记录原生生图和规划费用、阻止交付且不重新生成；证据留存失败也不能丢失已经发生的调用费用。

微距规划同时收到真实原图尺寸和原图层的未放大尺寸；供观察的放大预览不能冒充原生分辨率。原细节裁剪最多线性放大四倍，超出时在购图前拒绝并反馈实际倍率，规划须采用合适尺寸的细节插图与原产品视图。最终白边、锯齿与照片质感检查保持。

独立文字证据增加八个原图像素的真实上下文和最高八倍最近邻观察，避免弯曲基线或版权字形被近似定位边界切掉，不改变交付图片。复杂金属部件定位与局部换色的印刷面定位保留有界精确思考；普通来源选择、独立读字、抠图和背景布局继续使用简短完整 JSON 的配置。

服装人工对照发现一张模特图把原来的五颗扣子画成六颗，虽自动审核通过仍拒绝验收。最终审核新增 `garment-count-review-v1`：按来源与实际成品逐颗核对可见纽扣和扣件，数量变化拒绝 `protected_attributes`，遮挡或不确定不能冒充通过；幂等键绑定该新版本，原来的六项条件完整保留。固定五扣正例与六扣反例的真实模型资格检查仍待完成。

局部墙面换色的整图重绘可能在严格蒙版合成后产生不连续的边缘。仅在用户选用 auto 且完整指令属于已支持的明确墙面换色语法时，候选改为使用原图明度与纹理的本地颜色提案；指定其他执行路径或带额外操作的指令不采用该提案。最终实际交付图仍须通过原有视觉审核、原图尺寸和蒙版外零像素变化检查。拒绝时保留原候选且不购买替代图片；正负回归均验证原审核生效，没有改写拒绝结论。真实原图复测待完成。

目标商品框的规划 schema 收紧为原生校验已有的 0.04–0.96 留边范围，避免向规划器声明 0–1 可用、派发前却按更窄边界拒绝。原始照片中的授权裁剪窗口仍采用自身 0–1 坐标，不改变裁剪权限。越界规划继续拒绝，不裁掉商品来通过检查。

最终六项保真审核增加明确的物理接触规则：已批准的横杆、挂点、手、包或承托面必须与商品实际接触；有可见空隙时拒绝 `requested_change`，不能因商品像素保留而通过。平面图形设计不凭空要求新增承托物。审核使用独立的 `physical-contact-review-v1` 幂等版本，避免复用旧审核结论；实际反例资格检查仍待完成，不构成此项已验收的声明。

国内主图真实复测有一份布局在两次规划中重复重叠。候选新增有界商品布局编译：只在商品框相互碰撞时尝试同屏内的局部平移和最多 10% 的等比缩小，保留来源索引、授权裁剪、横向次序及全部文案；无解时返回原规划继续拒绝。编译结果、算法版本和原始规划哈希在购图前冻结，随后重新执行原有边界、碰撞、微距最多四倍放大、字号、像素和最终保真校验。未调整的合法规划保持原样，不增加购图次数。

原生审核器从实际观察生成的短 OCR 失败证据可能不足原有诊断字段的八字下限，导致不合格画面被误报为 `HARNESS_INVALID_OUTPUT`。候选只为服务端计算的短失败证据补充实际检查名称和观察类型，保留原文字与全部失败判定；不修饰模型原回复，不改八字下限，也不把失败改成通过。长短两类未授权文字均通过原生负向回归。

当前真实验收仍有明确未通过项：白底图中透明吊牌内的原展示架横线无法在保留原印刷像素时直接消除；部分国内主图的挂件未与生成的支撑横杆实际接触，人工验收拒绝，不能由自动审核的通过覆盖。该状态下不切换生产。客户已说明没有更清晰原图，小字独立 OCR 不再继续反复试换模型。

首次真实白底到亚马逊链路暴露了来源指针在中间适配层被过滤的问题。该轮操作员测试已通过取消接口停止后续派发，已发生的五次生图均已返回并保留回执，该轮不计验收通过。候选随后补齐有界字段保留：只有完整的归属字段、哈希和已通过合成回执相符时才传递指针，不允许自由文本或凭据随之保留。新增合成、适配、真实存储及输出记录的联合回归；旧适配层可稳定复现指针丢失失败。下一轮验收在购图前核对实际继承的原始图层，未继承即停止。

白底成品再次抠图可能把白色背景带入半透明边缘。当前候选对同工作区中已完成、已交付的白底任务保留来源指针；后续亚马逊任务可复用其原始 RGB/alpha 图层。复用前逐项核验任务归属、冻结回执、原图和图层字节、背景和精确重合成哈希；只支持完整且无歧义的全部商品映射。旧上传白底图继续执行普通严格抠图。继承图层仍须重新通过完整抠图审核和最终保真审核，不能复用历史通过结论，也没有扩大边缘擦除面积。
