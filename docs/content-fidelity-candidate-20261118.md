# 商品保真候选修复（尚未发布）

此分支仍处于真实接口和人工验收阶段。完整 CI、所有约定生成入口、下载与 ZIP、原生尺寸和内容保真全部通过后，才可切换生产镜像。自动审核通过不替代人工对照，历史任务不能因本次检查被自动重新购买。

## 图案与文字

适用的换背景、白底、参考混剪、主图和亚马逊画面使用独立背景板与原图商品图层。分割模型只预测 alpha；图层 RGB 与原始照片的对应区域逐字节核对，保存来源图片、裁剪区域、图层、背景和合成结果的 SHA256。允许的商品变换是保持比例的缩放与平移。换色、换模特、试穿和姿势迁移不采用这条路径，避免撤销用户明确要求的修改。

先检查供应商背景原图的实际尺寸、比例、最低尺寸和透明度，再进行商品合成；无合格原生背景时禁止补边、改画布或重采样来通过门禁。背景原图保留为私有证据。最终图片明确属于原始商品像素合成图，不能宣称其字节是未经修改的供应商完整原图。

U-2-Net ONNX 在镜像构建时从固定公开来源下载并校验 SHA256；运行时不下载模型。NumPy 和 OpenCV 使用带哈希的依赖锁文件，许可随源码保留。每个工作进程串行使用一个模型，通常执行两次局部推理；歧义时至多追加一次保留完整选择区域的上下文调整，歧义阈值不改变。原图与抠图配对进行完整性审核，任一未解决缺陷均阻断生图。

空间选择采用完整原图清单和明确的对象 ID。服务端验证所选 ID 确为用户指定的下排、上排或左右子集，再从清单构造唯一记录，避免规划器复制整段对象记录时改写坐标或文字。营销画面由原批准方案决定每屏商品与文案；屏内坐标经过边界、重叠和双屏接缝校验，不把原图裁剪坐标用于输出布局。

细小反光五金可在原始轮廓附近进行受限的源像素边缘细化。若首次抠图审核仍发现小缺陷，只允许一次有坐标、面积和区域限制的 alpha 修正，然后以新哈希重新审核实际像素；不得重复审核同一失败图以碰运气。删除背景仅限未印刷的顶部五金区域，不能删除人物、图案或文字。修正后的四项抠图条件与最终全部保真条件仍须通过。混剪先量测所选原商品的实际可见比例，再生成统一缩放可满足的规划。

同一任务、同一来源字节、选择和模型版本对应的抠图只验收一次，并复用完全相同的已验收像素；失败的相同抠图也保留失败标记，不能换一个套图条目反复审核。每张最终图片仍执行全部原有校验。营销背景指令明确要求渲染批准的标题和说明，空背景仅指不绘制商品，不能导致已批准文案丢失。

分割上下文按原图商品清单中的空间单元收紧，避免白底中间图的相邻商品进入推理裁剪。原有 95% 连通性阈值同时用于首次分割与最终边缘细化，不能在合并遮罩后重新引入碎片。原生详情中明确批准的微距模块可以从已验收完整图层裁取原像素细节；整枚商品模块仍要求完整主体，所有裁剪窗口均在购图前验证并冻结。

明确要求把金色五金改为银色时，候选路径可定位原照片中的金属扣、环与连接件，在有界金色掩膜内保留明度进行银色转换。每块区域和总修改面积均有限制，其他像素与原图逐字节不变；不为此购买重绘图片。其他目标颜色、材质或修改仍采用既有编辑路径。该路径仍执行六项视觉保真审核和独立文字转录。

批准的营销标题与说明采用固定 Noto Sans CJK SC 字体渲染，不能交给背景生成器重新拼写。每段批准文案必须有唯一文字框；文字框不能相互重叠、覆盖商品或跨越双屏接缝，并须能以可读字号完整排入。布局无效时最多修正一次规划，再次失败即停止购图。字体固定来源提交、SHA256 和 OFL 许可，只在镜像构建时下载。供应商背景仍先通过原生画幅门禁，商品和文字合成不改变其画布尺寸。

## 回执与审核

派发生图前冻结来源哈希、选择、图层、背景描述、布局和实际传输提示词。原生详情子调用必须对应已授权的父工作区、任务、条目、尝试及精确签名 token；批准方案、逻辑幂等键和原生调用栅栏保持。不同子调用的私有证据分别绑定，不能覆盖同一尝试中的另一张图片。

六项保真审核和各功能原有审核均保留。参考混剪另提供经冻结来源绑定的原图放大区域，避免把原图已有特征或反光误判成新增内容。缺字段和无效合同记录字段路径、检查名称和次数，不向运行日志写入原始图片、提示词或凭据。历史缓存图片也必须进行来源与文字审核；不能以复用为由跳过验收。

混剪提供同一缩放比例的原商品与实际候选区域并排证据，完整候选图仍供构图、水印及来源泄漏检查。构造证据前额外核对不透明商品像素，出现任何差异即失败。来源识别、独立文字转录、局部五金选择和混剪细节审核支持显式配置 `POLARIS_IMAGE_FIDELITY_PRECISION_MODEL`；一般规划、背景投影和抠图审核保持原模型路由。模型返回的失败条件不得由服务端改写为通过。

未知供应商结果继续查询原任务，不能新建替代订单或切换模型重复购买。质量拒绝保留私有候选并记录原有费用；规划与审核费用一并汇总，会员结算仍按既有交付规则执行。

详情素材分析的明确截断回复加入既有两次修正上限，与字段、参考覆盖错误共用次数。新调用须保留相同来源、模型与完整校验，并保存独立回执和所有费用。原回复未完成、被篡改或与修正父回执不符时继续阻止派发。

## 发布边界

原始客户图片、输入、环境文件、供应商凭据和验收产物只保留在受限测试目录，不进入仓库。真实验收使用独立数据库、存储和操作员预算，不扣客户积分。

上游原生尺寸支持已经取得用户明确扩展授权。尺寸与质量参数透传的候选代码仍需与实际上线基线逐项合并核对。只有完成真实原图验收的供应商绑定和尺寸可以加入生产白名单；不能据此扩大其他通道能力。生产发布前备份配置与数据库，保留回滚镜像，并再次检查最新任务和活动调用。

背景布局规划同时看到每个独立商品的原图层与实际宽高比，不能把同一个整组商品框重复用于各成员。重叠错误反馈明确指出冲突条目与坐标，原有不重叠、边界、字号及文字保真条件保持。CI 浏览器使用 Chromium 实际发布的 DevToolsActivePort，避免预约端口释放后的竞争；启动期限与页面断言保持，并保留有界标准错误用于定位故障。
