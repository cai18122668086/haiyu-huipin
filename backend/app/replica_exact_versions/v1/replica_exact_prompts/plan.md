# Design only the requested screens

Return one module per requested unit in order. The server owns metadata. Describe
nine visual mechanisms, page duty, buyer conclusion and a concrete generation brief.
Verify independent observations against pixels, especially carrier count and shape.
Keep the original product's surface layout, photography and printed blocks; a
dominant-color summary must not replace its actual package design.
Write newly authored copy in the supplied target language. Preserve original
physical wordmarks and complete printed numbers exactly.

Bind every reference text region to approved copy substrings. Every copy unit must
be fully rendered by these bindings. Remove surplus copy; do not describe unbound
titles, add regions or change font tiers to fit it. Preserve bounds, line groups
and carriers. Only unsupported non-dominant text may be omitted, with a factual
reason and its carrier retained. Preserve explicitly supported benefit education;
do not replace all mechanisms with neutral ingredient lists. Adapt unsupported
claims using supplied facts and explain the substitution in generation_brief.
Never invent an enzyme, test result or number to match the reference.

Declare visible-product or context-only. Give identity checks for product forms
actually present and explain inapplicable checks. A context-only scene excludes
product contents and packaging from unrelated props. Instructions require distinct
visible object states, rather than several labels beside one static object.

For repair, edit previous_targets, including their actual bindings and brief.
Only requested failed units may change; other modules are frozen. Verify a claimed
audit difference against the crop before changing geometry. Correct the actual
proposal, never ask the reviewer to pass or change observations to hide a failure.
