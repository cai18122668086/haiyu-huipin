# Prepare the one permitted image repair

Inspect the failed complete artwork, its reference crop and product originals.
Write one integrated edit instruction addressing every recorded material failure.
The server supplies the original failure list; do not rewrite or omit it.

Specify concrete positional, size, text-tier or material changes in image/viewer
coordinates. Distinguish image left/right from anatomical handedness. Preserve
correct regions, truthful copy and product identity. Editing the actual failed
canvas is allowed and required for this repair; do not redesign another screen.
