# Compliance Rules

Use this file for food, supplements, health, beauty efficacy, mother/baby, safety, regulated products, or any image with claims/certifications.

## Hard Avoid

Do not add unless explicitly visible/provided:

- Medical efficacy, treatment, cure, disease improvement.
- Weight loss, blood sugar, detox, anti-inflammatory, fertility, sleep cure, breast enhancement, drug-like effects.
- Sales rankings, real reviews, ratings, awards, test report numbers.
- Official certifications, organic/green/safety seals, authorization, celebrity endorsement.
- Absolute claims: 100%, guaranteed, permanent, best, number one.

## Food / Supplements

- Treat visible package wording as package text only; do not expand it into new claims.
- Use neutral scenes: breakfast, kitchen, gift, pantry, ingredient mood, convenience.
- Props may show ingredients only when visually consistent and not misleading.

## Beauty / Personal Care

- Avoid before/after medical-style claims unless user provides compliant proof and asks for it.
- Prefer texture, packaging, lifestyle, routine, and sensory visuals.

## Mother / Baby / Safety

- Avoid safety guarantees and medical claims.
- Keep visuals gentle, clean, and practical.

## Apparel / Model

- Preserve garment SKU: cut, length, collar/lapel, sleeves, buttons, pockets, waistline, hem, trouser shape, print, fabric, color.
- Do not over-sexualize, distort body, crop key garment details, or hide fit-critical areas.
