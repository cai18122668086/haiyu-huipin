# Platform Defaults

Use this file when the target platform is stated or can be inferred.

## Taobao / Tmall

- Default ratio: `1:1` main image.
- Style: premium ecommerce commercial photography, strong product presence, clean but conversion-oriented.
- Text: no text by default unless user asks; if text is requested, keep it short and readable.
- Composition: product occupies 60–82% of canvas; leave safe margin for platform cropping.

## Amazon

- Default: white or very clean product-first image.
- Prefer minimal props and no promotional copy on main image.
- Avoid badges, certification claims, medical/health claims, ratings, reviews, and price-like graphics.
- For A+ or secondary images, allow lifestyle scene and clean comparison modules if requested.

## TikTok Shop / Short-video Commerce

- Default: high-attention scene image with clear product silhouette.
- Use lifestyle/action context, but keep product large and readable on mobile.
- Avoid clutter and fake platform UI.

## Xiaohongshu / Social Seeding

- Default: lifestyle atmosphere, natural light, editorial styling.
- Product still must be the focus; props should support mood, not hide SKU details.
- Avoid over-commercial hard-sell badges unless requested.

## Independent Store / DTC

- Default: polished brand campaign look.
- Keep more whitespace and a cleaner premium visual hierarchy.
- If brand palette is known, use it; otherwise infer softly from product packaging.
