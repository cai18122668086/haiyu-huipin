# Buyer Demand Strategy

Use this file before page planning. Cross-border detail pages must start from buyer demand, not from a fixed visual template.

## Information Confidence

Classify every candidate selling point before using it:

- `confirmed`: explicitly provided by the user, clearly visible in product images, or readable on packaging.
- `reasonable inference`: conservative inference from visible product form or normal use; write as usage fit, not as a hard claim.
- `needs confirmation`: unknown material, size, parameter, efficacy, certification, sales, review, compatibility, ingredient ratio, authorization, or test result.

Use confirmed points first. Use reasonable inference with conservative wording. Never place `needs confirmation` facts as on-image claims.

## Buyer Demand Map

Create six to ten buyer questions or concerns and prioritize by purchase impact:

1. trust and risk reduction;
2. functional usefulness, style fit, or emotional value;
3. usage scenario and daily fit;
4. material, structure, taste, texture, craft, or design proof;
5. convenience, storage, portability, operation, pairing, or preparation;
6. specification, size, compatibility, package contents, care, or SKU confirmation;
7. final choice confidence.

## Product Type Strategy

Choose the primary product strategy:

- `standard / functional product`: practical function, operation, structure, efficiency, comparison, scenario fit, and confirmable parameters.
- `non-standard / aesthetic product`: design language, silhouette, material texture, visual taste, pairing scenes, and atmosphere.
- `consumable product`: taste, texture, usage frequency, preparation, packaging convenience, visible/provided ingredient information, and daily scenario.
- `gift / emotional-value product`: packaging, ceremony, recipient scenario, display value, atmosphere, and conservative gifting reasons.

If a product spans multiple types, choose the strategy that answers the strongest buyer concern.

## Demand-To-Selling-Point Match

For each planned screen, define:

- buyer demand;
- matched selling point;
- confidence level;
- buyer-facing copy direction;
- visual proof method;
- information that must not be invented.

If no confirmed selling point supports a demand, use a conservative scene-based benefit or mark the missing fact as needing confirmation.
