# Visual Quality Rules

Use this file before prompt writing whenever the output should be a finished ecommerce image, especially for Ozon/Wildberries vertical marketplace images.

## Product Photography First

The default visual should feel like a polished product photo with useful selling information, not like a parameter poster.

- Make the product the visual hero, usually occupying 55-75% of the image for cover, scenario, material, stability, and summary pages.
- Use believable surfaces, realistic shadows, contact points, and foreground / midground / background depth.
- Prefer real home, office, tabletop, cabinet, desk, or studio-home scenes over empty gradient backgrounds.
- Let material quality come from highlights, reflections, texture, scale, and crop, not from decorative badges.

## Ozon / Wildberries Vertical Aesthetic

For Russian marketplace vertical PDP images:

- Use the requested vertical size, commonly `900x1200` or 3:4.
- Use Russian short copy by default.
- Keep the layout clean and commercially readable, but not cheap.
- Use one main headline, two to three selling labels, and at most four required parameters per image.
- Use modern sans-serif typography; keep the headline below roughly 15-20% of the canvas height.
- Keep enough product area visible; copy must not dominate or crush the product.
- For hardware, brackets, electronics, stands, mounts, and tools, prefer: black product, warm light wood surface, light grey or cold blue background, controlled technical accents, realistic metal highlights.

## One Visual Mechanism Rule

Each image should choose one primary visual mechanism:

- product hero;
- lifestyle scene;
- material or structure close-up;
- installation process;
- VESA / size compatibility card;
- stability proof;
- summary checklist.

Do not combine all mechanisms in one image. Avoid putting cards, icons, measurement lines, arrows, process steps, and multiple diagrams together unless the page is explicitly a specification/instruction page.

## Cheap Template Bans

Avoid:

- cheap blue-white infographic template;
- PPT card stack;
- oversized title filling the top of the image;
- repeated three-icon card layout;
- generic shield icons as the main design element;
- fake test badge;
- fake certification or guarantee badge;
- table-like parameter dumping;
- identical layout rhythm across multiple images;
- small floating product on a large empty background.

## Russian Copy Rules

- Use short Russian phrases, not long paragraphs.
- Prefer concrete buyer language over technical jargon.
- Keep parameters accurate and compact.
- Do not let Russian copy overlap the product.
- If text accuracy is risky, use fewer labels and larger spacing.

## Product Reality Rules

- Prefer the reference product and reference TV/stand relationship over invented complex TV backs.
- Do not invent ports, certification labels, steel cross-sections, screw counts, tool sets, test rigs, or package contents.
- For confirmed specs such as load capacity or VESA, use concise text and restrained visual support. Do not create fake laboratory tests or stress-test scenes.
