# Reference Page / Competitor Visual Analysis

Use this file when the user provides reference images, competitor detail pages, layout references, or asks to follow a visual direction.

## Default Behavior

Default to referencing the visual style. Extract the style direction and sales rhythm, then rebuild them for the current product, platform, and buyer demand.

Reference:

- overall visual tone and product price impression;
- color mood and contrast logic;
- lighting direction and material rendering;
- image density and whitespace logic;
- information hierarchy;
- page rhythm and role sequence;
- composition devices;
- label, callout, card, icon, and annotation style;
- scene atmosphere and prop logic.

Do not copy:

- brand name, logo, watermark, slogan, or brand color identity when it is uniquely identifiable;
- exact wording, reviews, ratings, certifications, test badges, platform badges, or discount claims;
- exact layout, exact object placement, or one-to-one page composition;
- unique ornaments, proprietary graphic assets, icons, illustrations, or recognizable design marks;
- unsupported claims from the reference page.

## Reference Visual Style Lock

When reference material is provided, create a `Reference Visual Style Lock` and include it in every prompt. It should describe:

- reference-derived tone;
- color and lighting direction;
- density and hierarchy;
- label/card/callout style;
- scene atmosphere;
- visual rhythm to preserve;
- elements that must not be copied;
- adaptation direction for the current product and platform.

## Reference Page Analysis

For reference detail pages, analyze:

1. Page roles: cover, concept, ingredient, craft, colorway, detail, scene, comparison, process, information, or summary.
2. Information hierarchy: main title, selling-point labels, explanatory copy, cards, icons, callouts, or decorative symbols.
3. Visual devices: glass frames, hanging display, collage, detail zoom windows, bottom information bands, technical annotation lines, process arrows, or comparison zones.
4. Rhythm: which pages show the full product and which rely on macro, scene, process, or information structures.
5. Reusable logic: learn the structure and visual style direction, but rebuild the page task table for the current product.

## Copy And Compliance

Do not transfer competitor claims to the current product. Any claim must be supported by the user's product information, visible packaging, or conservative inference. Treat copied certifications, ratings, reviews, and test data as forbidden unless the user provides proof for the current product.
