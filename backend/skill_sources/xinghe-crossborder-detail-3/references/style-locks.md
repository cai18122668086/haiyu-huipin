# Style Locks

If the user gives a visual style, brand color, reference image, mood, or layout requirement, follow the user and adapt only what is missing. If reference images or competitor pages are provided, create a `Reference Visual Style Lock` using `reference-page-analysis.md`.

## Global Rule

Every module in one set must share the same Campaign Style Lock and Style System Lock. Only the module purpose, image composition, product angle, labels, and scene may vary.

Premium does not mean empty whitespace, gold decoration, or sparse text by itself. For premium, luxury, international brand, or high-end requests, build quality through layered editorial composition, strong product scale, controlled shadows, material texture, foreground/midground/background depth, magazine-grade crop, and purposeful negative space. Avoid marketplace infographic styling, gold badge circles, beige icon rows, and small floating product layouts.
