# Category Playbooks

Use these playbooks after Product Image Analysis, Information Confidence, and Product Type Strategy. If the user provides a different selling strategy, follow the user.

## Product Type Overlay

- Standard / functional products: utility, structure, operation, efficiency, comparison, scenario fit, and confirmable parameters.
- Non-standard / aesthetic products: design language, silhouette, material texture, styling imagination, mood, identity, and perceived value.
- Consumables: taste, texture, serving, preparation, usage frequency, packaging convenience, and visible/provided ingredient information.
- Gift / emotional-value products: packaging, ceremony, recipient scenario, display value, atmosphere, and conservative gifting reasons.

Do not force aesthetic, gift, or consumable products into a purely functional manual. Do not force functional products into empty editorial posters.

## Beauty / Makeup / Personal Care

Buyer objections: what it does, texture, finish, use steps, portability, skin/ingredient concerns, routine fit, proof without exaggeration.

Default modules:
1. Sensory hero benefit
2. Texture / mist / applicator proof
3. Visible package claim translated conservatively
4. Finish / look / sensory texture
5. How to use
6. Vanity / pouch / travel scenario
7. Routine fit
8. Summary / choice reducer

Compliance: do not invent ingredients, hypoallergenic, dermatologist-tested, waterproof, sweatproof, medical or skin-treatment claims.

## Fashion / Apparel / Accessories

Buyer objections: fit, silhouette, fabric texture, comfort, details, styling, care, SKU/color choice, perceived value.

For aesthetic-driven fashion, lingerie, accessories, or non-standard apparel, lead with visual desirability, design language, silhouette, textile feeling, styling mood, and perceived value. Keep comfort, care, and practical features as supporting proof unless the user asks for a functional sales path.

Default modules:
1. Visual desire / style benefit
2. Fit and silhouette
3. Fabric texture / material feeling
4. Movement, drape, or wearing comfort
5. Detail callouts
6. Styling scenarios
7. Care, color, or SKU choice
8. Lookbook-style summary / choice confidence

Use Model Identity Lock. If model consistency is unstable, crop below face, use side/back view, ghost mannequin, hanger, or flat lay.

## Electronics / Accessories

Buyer objections: compatibility, ports/buttons, performance context, setup, durability, portability, heat, what is included.

Default modules:
1. Hero value
2. Compatibility caveat / proof
3. Interface / button detail
4. Setup steps
5. Performance context without fake specs
6. Portability / desk / travel scenario
7. Problem-solution comparison
8. Package contents / summary

Do not invent wattage, battery, speed, certifications, compatibility lists, waterproof ratings, or benchmark scores.

## Home / Kitchen / Storage

Buyer objections: size fit, material, storage, cleaning, stability, scene fit, installation, daily convenience.

Default modules:
1. Hero home benefit
2. Size-in-context
3. Material / surface detail
4. Storage or organization proof
5. Cleaning / maintenance
6. Installation / use steps
7. Multi-room scenarios
8. Summary / package contents

Translate dimensions into counter, cabinet, sink, table, hand, or shelf context only if visible or provided.

## Food / Beverage / Supplements

Buyer objections: taste, ingredients, serving method, storage, dietary fit, safety, use occasion, pack count.

Default modules:
1. Hero appetite / use moment
2. Ingredient or texture visual
3. Serving or preparation steps
4. Flavor / occasion
5. Storage / portability
6. Pack / quantity if visible
7. Lifestyle scenarios
8. Summary / choice reducer

Do not invent health benefits, treatment claims, certifications, nutrition numbers, organic/non-GMO claims, or allergen-free claims.

## Pet Products

Buyer objections: pet fit, safety, size, cleaning, durability, comfort, use scenario, package contents.

Default modules:
1. Hero pet-owner benefit
2. Size / fit context
3. Material / comfort detail
4. Use steps
5. Cleaning / maintenance
6. Indoor/outdoor scenario
7. Problem-solution comparison
8. Summary / package contents

Avoid veterinary, treatment, guaranteed safety, and breed-specific claims unless provided.

## Baby / Kids / Maternity

Buyer objections: safety, material, age/size fit, ease of cleaning, parent convenience, scenario fit, portability.

Default modules:
1. Parent benefit
2. Visible safety structure without absolute claims
3. Material / softness visual
4. Size / age only if provided
5. Cleaning / maintenance
6. Parent one-hand convenience
7. Home / travel scenario
8. Summary / package contents

Use conservative language. Do not say "100% safe", "non-toxic", age ranges, certifications, or medical benefits unless provided.

## Outdoor / Sports / Travel

Buyer objections: portability, durability, weather/context fit, capacity, comfort, setup, storage, scenario.

Default modules:
1. Hero active benefit
2. Portability action
3. Material / structure detail
4. Capacity translated into scenario
5. Setup / use steps
6. Outdoor / gym / travel scene
7. Storage / cleaning
8. Summary / package contents

Do not invent waterproof, impact-proof, load-bearing, insulation, or endurance specs.

## Auto / Tools / Hardware

Buyer objections: compatibility, installation, durability, size fit, use steps, storage, safety, included parts.

Default modules:
1. Hero problem solved
2. Compatibility / fit caveat
3. Component detail
4. Installation steps
5. Use scenario
6. Durability visual without fake tests
7. Storage / included parts
8. Summary / choice reducer

Do not invent vehicle models, safety certifications, torque, load rating, waterproof rating, or professional endorsements.
