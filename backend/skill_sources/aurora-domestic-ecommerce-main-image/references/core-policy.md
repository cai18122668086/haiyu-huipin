# Core policy

## Authority order

Apply `USER_FACT → EVIDENCE_DERIVED → EXPERIMENTAL_PATTERN → ENGINEERED_DEFAULT
→ MODEL_FREEDOM`. A lower layer may never invent or strengthen a higher-layer
fact.

## Product and references

- Bind every original same-product image to an explicit evidence ID and role.
- Use `PRODUCT_IDENTITY_AUTHORITY` for identity and supported views.
- Use `STYLE_REFERENCE_ONLY` only for an Agent pixel-audited accepted page and only for
  typography, color roles, information surfaces, graphic geometry, lighting,
  material finish, and photography finish.
- Never inherit product pose, crop, camera, loaded contents, operating state,
  scene geometry, page skeleton, copy, offer, or product facts from a style
  reference.
- Discard source wall, floor, props, clutter, color cast, lighting, and camera
  perspective unless the user explicitly asks to preserve the environment.

## Claims and proof

Select claims only from verified user text. Bind every proof-bearing macro,
pointer, line, glow, label, person, animal, component, or action to visible
current-product evidence. If the target is unsupported or ambiguous, remove the
device and retain complete fact-bound text.

Use real current-product photography, components, contents, actions or credible
scenes as the product anchor. Allow controlled visual rhetoric to amplify the
benefit, while accurate text carries invisible facts and conditions.

## Priority

Preserve: product identity → factual compliance → page role/lead benefit →
commercial impact → legibility → campaign consistency → decoration.

## Six-page contract

Compile exactly one search listing cover followed by five carousel pages. Freeze
the same typography roles, palette roles, graphic language, information-surface
geometry, photography finish, and density band across the set. Give every page
a unique view/crop, scale, product state, scene geometry, subject anchor, layout
family. Vary enough visual structure to keep page duties distinct, but do not
force every camera, reading-path and evidence dimension to be unique.

## Agent execution ownership

Treat every rule as an Agent action, not advice for the user. After the user
authorizes the six-image task once, inspect every generated image directly,
reject weak drafts, prepare targeted repairs, recalibrate style from accepted
pixels and continue sequentially without asking the user to perform routine
quality control. User-provided facts are accepted without re-verification. Ask
only when a new campaign direction would replace the approved plan or the user
must decide what to change after the automatic repair budget is exhausted.
