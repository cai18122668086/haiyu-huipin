# Style / Layout Separation

Use one Campaign Style across the set without reusing one layout skeleton.

## Style may control

- typography family and type treatment;
- color roles and emphasis color;
- background materials;
- lighting language;
- shared graphic motifs;
- photography finish.

## Style must not control

- layout archetype;
- product anchor or scale;
- composition axis;
- title position;
- reading path;
- card topology.

When an accepted generated page becomes a style reference, bind it as `STYLE_REFERENCE_ONLY`. Original same-product images remain the sole product-identity authority.

## Hard gates

- five distinct layout archetypes;
- no adjacent skeleton reuse;
- at least three product anchors;
- at least three composition axes;
- at least three title positions;
- at least three card topologies;
- one Campaign Style Lock across all pages.

Reject a set that passes style consistency but repeats the same page skeleton.
