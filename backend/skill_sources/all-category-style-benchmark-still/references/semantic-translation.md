# Semantic translation protocol

For each source semantic, record the source observation, inherited mechanism IDs, a product-native target world, product fact IDs, palette decision, and replacement copy. In the target plan, use the exact source-semantic ID as the key and keep each value as an object, for example `{"M1":{"target_world":"product-native outdoor world","product_facts":["F01"],"retain_literal_source":false}}`. A flat object such as `{"product_facts":["F01"],"translation":"..."}` is invalid because it cannot prove which source semantics were translated. The source environment is a semantic input to translate, not a backdrop to retain. Literal source labels, brand assets, package shapes, props and copy are forbidden by default. A translation is invalid when it only swaps color or product name, has no current-product evidence, or retains a source-world element without a fact-supported reason.
