# Audit protocol

For detail plans, review the full ordered set against the reference before generation: preserve the benchmark's physical order, opening/content function, density, transitions and visible information. Supplied evidence images are optional sources; they may remain unused when the mapped benchmark step does not call for them. If a fact is used, check its scope and evidence boundary. Repeated source treatments are valid when the benchmark repeats them; do not reject them merely because copy is repeated. Inspect final visible copy for internal headings such as 收束/总结/结尾; these planning roles must never become customer-facing labels. Check the resulting images for omissions, unsupported selected claims and leaked planning terms during the existing visual audit.

Compliance review uses four tiers rather than a flat blacklist. Ordinary product descriptions can pass on confirmed or directly observed facts; evidence-gated claims need a bound fact and supporting source; category-sensitive terms require category-aware review; only clearly prohibited language is an automatic failure. Do not fail a normal specification or usage sentence merely because one word has a higher-risk meaning in another category.

Every audit names its provenance (`fixture`, `manual`, `visual_model`, or `real_imagegen`) and records fresh observations. Required dimensions are route-specific unioned with shared checks: style inheritance, product identity, product colors, product material/shape, product semantics, fact safety, originality, typography, density, safe zones and `decorative_label_free`. Real visual audits must also provide `mechanism_scores` for all eight reference mechanisms, each at least 0.8; a single aggregate style score does not prove fidelity. Every non-fixture audit requires the local receipt recorded with the artwork. Re-read its original tool-returned file and compare actual dimensions and SHA-256 against the unchanged artwork copy. This is local file evidence, not provider attestation or proof of visual sharpness. Do not substitute an audit JSON assertion for the recorded original file. A fixture receipt cannot override a prior failed manual, visual-model, or real-imagegen audit. Check contamination for source brand, packaging, logo, SKU, competitor, copy, literal composition, source world and benchmark product/person pixels, and reject any unconfirmed product name, logo or wordmark rendered on the target product; set `unconfirmed_product_mark: true` in that audit when observed. Also reject handwritten, brush, calligraphic, marker or cursive lettering used as the text form; set `forbidden_typography_form: true` when observed. Reject only label carriers such as pill/capsule/chip wrappers, stickers, badges, label clouds and repeated boxed icon-caption components. Do not reject ordinary explanatory text or the reference's information density. A persisted generation block or missing current-Pair source-step binding is a pre-generation failure, not a visual exception. A failure cannot be changed to pass by editing a string; an explicit one-time targeted revision is the only recovery.
