# 安装与使用 — 对标二创·快版 API版 v1.0

本目录是一个自包含的 Agent Skill 包。解压后即可使用，不需要额外安装本包以外的代码。
**本版默认走 api 路由**（自有网关），适合接到网站 / 服务端。

## 一、放到哪里

把整个 `对标二创快版API版` 文件夹放到宿主的 skills 目录，宿主会自动发现 `SKILL.md` 与 `agents/openai.yaml`：

- WorkBuddy：`%USERPROFILE%\.workbuddy-ai\skills\aurora-remix-fast`
- 其他兼容 Agent Skills 的宿主：对应的 skills 目录

> 文件夹名用中文只是为了让你看得懂；宿主真正识别的标识是 `SKILL.md` 里的 `name: aurora-remix-fast`，
> 以及 `agents/openai.yaml` 里的 `display_name`。两者不要改。

## 二、环境要求

- **Python 3.10 或更高版本**
- 依赖包：

```bash
python -m pip install -r requirements.txt
```

首次运行前建议先做一次自检：

```bash
python -m compileall scripts
```

## 三、生图网关（本版必需）

本版默认走 api 路由，**必须由调用方提供网关**。三选一：

- 命令行：`--base-url "https://<你的网关>/v1"` + `--api-key "<key>"`
- 配置文件：`--config <配置文件>`（结构见 `provider-config.example.json`）
- 环境变量：`$IMAGE_PROVIDER_BASE_URL` / `$IMAGE_PROVIDER_API_KEY` / `$IMAGE_PROVIDER_CONFIG`

本包**不含任何 API 密钥**：`provider-config.json` 里是占位值 `REPLACE_WITH_YOUR_API_KEY`，
且**不会被隐式使用**。没有指明网关时，api 路由会直接拒绝执行。

⚠️ 网关地址**必须带 `/v1`**，少了会拿到前端 HTML，报 `provider returned no image data`。
⚠️ 图像端点不接受模型名 `auto`，要用具体模型名（如 `gpt-image-2.5-flare`）。

### 网站 / 服务端怎么接

1. 把网关地址与密钥放在**服务端环境变量**或一份配置文件里，不要写进代码、日志或对话。
2. 每次出图调用：

```bash
env -u IMAGE_PROVIDER_BASE_URL -u IMAGE_PROVIDER_API_KEY \
  python scripts/render_image.py \
    --prompt-file <run>/prompt.txt --out <run>/artwork.png \
    --reference "<产品身份图>" --reference "<对标屏>" \
    --size <W>x<H> --quality high \
    --config <你的配置文件> \
    --timeout 900 --overall-timeout 1800
```

3. 出图后核对 `<out>.receipt.json` 的 `base_url` 是不是你给的那个；不符即本次作废。
4. 单图 150–290s，**必须异步调用**（后台任务 / 队列），不要用同步请求卡住。

## 四、怎么用

放进 skills 目录后，给两张图（对标图 + 产品原图）并说要复刻即可，宿主会读 `SKILL.md` 按里面的流程执行。

```bash
# 备料 / 快检工具
python scripts/fastprep.py ratio <对标图>                    # 读尺寸 + 建议画布
python scripts/fastprep.py crop  <对标图> --out <dir> --spec "0,0,1,0.5;0,0.5,1,1"
python scripts/fastprep.py board --out <board.png> <图1> <图2>
python scripts/fastprep.py wmcheck <成图> --out <wm.png>      # 查水印
python scripts/fastprep.py zoom    <成图> --box 0.4,0.3,1,0.75 --out <z.png> --scale 3
```

## 五、目录结构

- `SKILL.md` — 技能主文档，宿主据此执行；这是唯一的行为权威
- `agents/openai.yaml` — 展示名与默认提示词
- `scripts/fastprep.py` — 备料 / 快检工具
- `scripts/render_image.py` — api 路由出图桥（OpenAI 兼容）
- `provider-config.json` / `provider-config.example.json` — 网关配置模板（占位密钥，不会被隐式使用）
- `requirements.txt` — 依赖清单
- `CHANGELOG.md` / `VERSION` — 版本说明
