# Durable-goods optional prior

Load only after explicit user opt-in. Treat this as `OPTIONAL_PRIOR`, never as
product evidence.

For seating, storage, carts, shelves, tables, cabinets, and other durable goods,
prefer complete structure, exact components, access, adjustment,
transformation, capacity, loading, or verified use relations. Warm neutral home
materials, controlled window light, material macros, and structured information
surfaces are candidates, not defaults. Never import a sample brand, SKU, color,
dimension, load rating, material, pose, camera, fixed page order, or complete
layout.
