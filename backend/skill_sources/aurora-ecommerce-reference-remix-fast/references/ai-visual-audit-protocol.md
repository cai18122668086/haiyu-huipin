# AI visual audit protocol

This protocol separates visual intelligence from deterministic state control.

## Planning observation

View the physical crop at useful resolution. Do not read a previous plan first. Describe visible relationships, not labels alone.

- Subject and scale: count, occupancy, crop, pose, product/person relationship.
- Layout: major regions, their proportions, containment, reading path and continuity.
- Carrier morphology: continuous band, asymmetric comparison, exploded assembly, report block, full-bleed scene, collage or real repeated cards.
- Commercial function: what each region makes the buyer believe and how regions support one another.
- Expression: camera angle, lens feel, lighting, contrast, depth layers, motion and negative space.
- Typography: block count, line silhouette, hierarchy, angle, weight, effects and placement.
- Presence: standalone brand, product-native mark, full person, partial body, hand only or none.
- Absence: elements the reference deliberately does not contain; absence is binding.
- Sequence: what this screen adds after the previous screen and passes to the next.

## Fresh plan audit

Open the crop again and write a second observation without copying the first. Compare the second observation with the declared contract. A plan fails when it is internally consistent but visually false.

Typical hard failures:

- convenient normalized boxes reused across visually different pages;
- evidence/trust closure mislabeled as feature cards;
- alternative pain followed by solution reduced to unrelated benefits;
- exploded structure planned as an ordinary product hero;
- independent brand added where no brand pixels exist;
- full-body count used to hide a visible hand-only interaction;
- all units forced into the same canvas ratio.

## Fresh artwork audit

Open reference and artwork side by side. Ignore earlier confidence and inspect actual pixels.

Write one observation for the reference and another for the artwork. Do not make them verbatim copies. Then compare each required dimension with unique concrete evidence.

Pass only when all material relationships survive. The following cannot compensate for one another:

- correct text cannot compensate for wrong composition;
- correct color cannot compensate for wrong carrier morphology;
- current product identity cannot compensate for missing commercial proof;
- attractive art direction cannot compensate for wrong page duty;
- a generic card row cannot replace a continuous report, comparison, trust or exploded structure.

When failing, name observable deltas that can drive one integrated edit. Example: “Lower-quarter continuous evidence band is missing; two equal product-detail cards were added instead, changing both morphology and trust function.”
