# High-risk cosmetic claim contract (v4.2)

Read this reference whenever the category is cosmetic and a fact uses `risk_route=HIGH_RISK_CLAIM`.

Each such fact must include a machine-auditable `claim_risk_contract`:

- `evidence_level`: regulatory record, documented test, packaging-only or user assertion;
- `allowed_phrases`: consumer-facing wording supported by the evidence;
- `forbidden_phrases`: stronger, absolute, medical, clinical or otherwise unsupported wording;
- `evidence_sources`: typed regulatory, report, package or user-material references;
- `effect_implication_allowed`: whether visual or textual effect implication is permitted;
- `qualification`: the minimum truthful use/audience/result condition.

Planning rejects a module when its visible copy contains a forbidden phrase attached to a high-risk fact. This contract does not prove a registration or test is authentic; the source reference must still point to supplied evidence, and unresolved source conflicts remain blocking.
# v4.3 ingredient visualization boundary

Ingredient and formula visuals must declare an evidence tier. Use authentic package/document evidence when the screen is evidentiary; use a truthful source/material macro when the supplied material supports it; otherwise use `CONCEPTUAL_NON_DIAGNOSTIC` visual rhetoric. Conceptual droplets, layers, paths and abstract particles must not imitate microscopy, molecular geometry, penetration into skin, laboratory results or a causal biological mechanism. The authorized ingredient name may be visible copy, but the visual itself does not upgrade the evidence ceiling.

For every ingredient/formula claim, machine-readable planning records the allowed wording, prohibited wording, source type, effect-implication permission and visual tier. A visually attractive ingredient orb is not proof of concentration, absorption, efficacy or clinical result.
