# 屏间衔接编排与方法选择

本层只补充屏与屏之间的连续性，不改变原有产品运营、卖点覆盖、屏数决策、画面表达、审核或重修规则。参考详情页只能提取可迁移的视觉语法，不能复制品牌、文案、数字、坐标或版式。

## 衔接原则

每个非首屏都要从前一屏接收至少一个可见线索，并向后一屏交付一个新的线索。线索可以是：

- 视觉载体：水流、叶脉、纸张肌理、能量线、奶油流动、粉末、金属圆环等；
- 空间方向：左到右、上到下、由中心向外、由局部放大到整体；
- 主体状态：完整商品、局部结构、原料、作用过程、使用结果、产品回归；
- 信息问题：是什么、为什么需要、如何作用、效果如何、如何选择或使用。

## 衔接模式

1. **连续场景**：保留同一环境、光线和材质，只改变景别或主体状态。
2. **载体接力**：上一屏的线索在下一屏换成另一种形态，例如水流变成衣物上的清洁路径，山脉变成证书背景，原料变成配方/结构示意。
3. **章节转场**：当故事从痛点转入功效、从功效转入信任或从信息转入购买时，用明确的色带、边框、章节标题或材质转折完成转场；转场仍需继承至少一个品牌DNA token。

## 可选的通用衔接语法

以下是跨品类的视觉语法，不是固定模板。规划器应根据当前对象、动作、空间和叙事职责择一作为主方法，必要时叠加一种轻量辅助方法；不能把所有方法同时塞进一屏。

| 方法 ID | 适用条件 | 可见做法 | 不应误用 |
|---|---|---|---|
| `EDGE_BLEED` | 上屏有清晰物体、材质或曲线边缘 | 让边缘在下沿/侧沿延续，下一屏从同一边缘自然展开 | 只用渐变冒充边缘；改变商品形状 |
| `PRODUCT_OVERFLOW` | 商品轮廓适合跨屏，且下一屏仍需商品线索 | 商品或局部真实轮廓越过分界，下一屏接住其运动方向 | 每屏都让商品越界；造成裁切残缺 |
| `BACKGROUND_STRINGING` | 系列需要统一世界观、色温或材质 | 共用同一色场、纹理、环境光或大背景，使模块像同一长画布 | 复制参考图的独占背景或版式 |
| `PERSPECTIVE_TURN` | 产品/结构/空间关系适合换视角解释 | 顶面→侧面、平面→立面、远景→俯视等视角转折，保留一个方向锚点 | 为了炫技改变产品比例、结构或事实 |
| `DECORATIVE_HANDOFF` | 没有可安全跨屏的主体，但有品牌图形语言 | 波浪线、丝带、叶脉、光带、框线或材质纹理从屏边接力 | 用装饰代替卖点证据；装饰喧宾夺主 |
| `GRAPHIC_OVERLAY` | 科技、参数、机制或多数据关系需要图形系统 | 半透明网格、轨迹、节点、刻度或章节色带保持同一图形语法 | 把图形当成检测、专利、实验或精确结构证据 |
| `SUBJECT_STATE_HANDOFF` | 故事有痛点→作用→结果或状态变化 | 上屏的问题对象在下屏变为作用过程/结果，保留对象或动线 | 只换标题，不呈现状态变化 |
| `CHAPTER_BAND` | 痛点、功效、信任、选择、收口等章节切换 | 用共享色带、材质面或章节标识完成转场，同时继承DNA token | 每屏重复大标题栏，页面变成目录 |

### 自动选择规则

规划器先为相邻屏识别“上一屏交付线索”和“本屏可接收线索”，再按以下优先级选择主方法：

1. 有明确物体/材质边缘且可继续展开：优先 `EDGE_BLEED`；商品轮廓适合自然越界时才升级为 `PRODUCT_OVERFLOW`。
2. 有可见的前后状态、作用过程或结果：优先 `SUBJECT_STATE_HANDOFF`，不要用装饰替代因果。
3. 有结构、部件、尺度或空间关系：优先 `PERSPECTIVE_TURN`；有数据/机制图形系统时可辅以 `GRAPHIC_OVERLAY`。
4. 有稳定的环境、色场或材质世界：优先 `BACKGROUND_STRINGING`，但必须改变主体、景别或区域结构。
5. 没有可安全跨屏的实体线索：选择 `DECORATIVE_HANDOFF` 或 `CHAPTER_BAND`，并明确它们只是转场，不承担核心卖点。
6. 若多个方法同样合适，选择对本屏买家问题解释力最高者；不得因为“看起来统一”而强行保留商品或复制上一屏构图。

每个模块的契约至少记录：`method_id`、`selection_basis`、`incoming_anchor`、`outgoing_anchor`、`spatial_direction`、`shared_invariants`、`allowed_change`。首屏只交付线索，不要求接收上一屏；收尾屏必须把线索收回购买利益或完整商品。

### 画面接缝合同（必须）

衔接方法选定后，必须进一步指定 `visual_handoff_type`、`source_region_previous`、`target_region_current`、`handoff_geometry`、`visible_overlap_required` 和 `continuity_strength`。它们描述的是边界两侧实际要看到的画面元素，不是故事概念。除章节转场外，默认要求边界处存在可追踪的同一物体、材质、曲线、动线、图形或状态关系；仅色彩相似、同一字体或同一背景氛围不算完成。生成时先构思上一屏与本屏的接缝，再安排主体和文字，不能在最后用装饰线临时补接。

审核时将“画面接缝”与“故事连续”分开判断：若边界元素凭空消失、方向/尺度断裂、两张图只是独立海报或没有实际可追踪的视觉承接，则判定画面衔接失败；轻微装饰差异、接缝附近的局部裁切或更强的本屏构图不单独触发重修。

## 屏间契约

规划时为每个相邻屏对填写可执行的简短契约：前屏交付线索、当前屏接收方式、当前屏交付线索、空间方向、必须保持的DNA，以及允许的主体变化。没有明确交付线索时，不得仅以“风格统一”作为衔接理由。

## 生成与检查

- 按顺序生成；前一屏接受后，**立即**提取其底部边缘的轻量视觉状态作为下一屏的边缘参考（harness 的 `continuity_edge_reference` 会在接受时生成）。该参考只用于色彩、材质、光线和动线，不得锁死下一屏版式或商品位置。
- 边缘参考是下一屏唯一的承接性图像参考。**缺失时必须先补提取再渲染**（对已接受的屏幕重新运行提取即可），不得用完整屏、切片或任何生成图顶替——完整屏会把上一屏的版式骨架和它自身的漂移一并注入下一屏（2026-09-17 垃圾桶项目 M01→P02–P05 的链式漂移就是这样发生的）。
- 每一对屏幕必须先分别完成原子合同，再由 pair compiler 重新编排为一份 `PAIR_PLAN_MERGE` 提示词；生图后端只接收这份合并稿。合并不是机械首尾拼接，必须写清上方窗口的视觉载体如何进入接缝、在接缝中发生什么变化、下方窗口如何接住，以及镜头方向、尺度、光线、材质和氛围如何连续。合并稿使用单一 3:8 画布锁和固定 3:4 窗口，不能把两份独立 3:4 画布提示直接首尾拼接。
- 检查相邻两屏的色彩/材质/光线、载体、动线和叙事问题是否至少有两项连续，同时检查主体、景别或结构是否有有意义变化。
- 轻微装饰差异、概念性细菌/分子感图形变化、非主张型步骤编号不触发重修；只有导致页面像不同项目、动线断裂、故事顺序误读或商品身份丢失时才判定为严重断裂。
- 边缘参考缺失时仍可生成，不得中断整条顺序；记录为连续性降级，而不是把产品策划改写成另一套方案。

当使用 `EDGE_BLEED` 或 `PRODUCT_OVERFLOW` 时，边缘参考只锁定颜色、材质和运动方向，不锁定下一屏的主体坐标；当使用 `PERSPECTIVE_TURN` 时只继承空间方向和比例关系；当使用 `BACKGROUND_STRINGING`、`DECORATIVE_HANDOFF` 或 `CHAPTER_BAND` 时必须保留至少一个系列DNA token并允许主体完全换场。

## v4.1 方法专属接缝证据与方案合并（硬闸门）

“衔接方法已声明”不等于“衔接已完成”。每个 3:8 pair 的内部接缝必须在长页审计中填写一个 `internal_seam_evidence` 对象，至少指出：方法 ID、上方来源区域、下方目标区域、实际可见载体、接缝几何、是否存在硬切，以及带位置的像素观察。不得使用“画面连续”“符合计划”或“位置方向可追踪”等泛化句替代证据。

方法与最低可见证据一一对应：

- `EDGE_BLEED` / `PRODUCT_OVERFLOW`：同一边缘、商品或真实部件轮廓必须跨过固定分界，`crosses_boundary=true`。
- `SUBJECT_STATE_HANDOFF`：同一对象或动线在分界两侧发生可见状态变化，`state_relation_visible=true` 且 `direction_continuous=true`。
- `PERSPECTIVE_TURN`：同一结构的方向锚点和尺度/平面关系在分界两侧可追踪，分别填写 `perspective_direction_continuous=true` 与 `scale_relation_visible=true`。
- `BACKGROUND_STRINGING`：同一色场、纹理或环境光真实跨界，`shared_field_continuous=true` 且 `shared_token_visible=true`。
- `DECORATIVE_HANDOFF` / `GRAPHIC_OVERLAY`：同一波浪、光带、网格、轨迹或节点触及边界两侧，`carrier_crosses_boundary=true`、`shared_token_visible=true` 且 `direction_continuous=true`。
- `CHAPTER_BAND`：允许叙事断开，但必须看到共享色带/材质/章节标识，`intentional_transition=true`、`shared_token_visible=true`，不能是误生成的硬分割。

pair 与 pair 之间不能假设像素相同，必须另填 `pair_transition_audits`：引用批准的 `transition_token`，说明独立长图的来源边缘、目标边缘和共享载体；`shared_token_visible=false` 或出现硬分隔线时不能标记为完整通过。内部 pair 接缝和 pair-to-pair 接缝任一缺少方法专属证据，长页不得判定 `PASS`。

## 不应发生的退化

不得把每屏都做成相同的商品大特写；不得把前屏完整海报缩小后当作后屏参考；不得为了衔接复制上一屏的主体坐标、文字区域或全幅模板；不得用背景植物、光效或通用渐变冒充实际叙事衔接。
