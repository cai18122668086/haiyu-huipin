# Ecommerce marketing format routing

The user only needs to upload current-product originals and benchmark images. Infer the output route internally; do not ask the user to name the format unless the supplied references genuinely conflict and a single coherent output cannot include both.

## Route signals

### SEARCH_COVER

Usually one square or near-square canvas, dominant product, immediate category recognition, one primary benefit, strong thumbnail contrast, and minimal reading time. Do not infer this route from a square ratio alone.

### CAROUSEL_SET

Several related canvases with shared product identity and visual DNA. Each page resolves a different buyer question. Avoid repeating the search cover with only new copy.

### DETAIL_PAGE

One long vertical page or ordered vertical modules. It builds a sales argument across overview, doubt/pain, proof, use/result, selection/trust, and closure as supported by evidence.

When a showcase board places several portrait detail-page columns side by side, treat each column only as a container. Count and crop every independent screen inside it, then traverse column-major and screen-by-screen: all screens in the first column top-to-bottom, then all screens in the next column. Do not emit one output per column unless fresh inspection proves each column contains exactly one screen.

### SELLING_POINT_CARD

One self-contained benefit/proof graphic, often used inside listings, PDP modules, feeds, or ad sets. It must still bind copy to a visible product-specific carrier.

### PROMO_POSTER

One campaign peak with a strong event, launch, seasonal, gift, or hero message. A poster may be vertical, square, or horizontal; hierarchy and viewing distance matter more than ratio.

### ECOMMERCE_BANNER

A wide or shallow canvas designed for rapid recognition. Reserve safe zones for cropping and interface overlays. Keep the product/value legible without dense detail-page copy.

### SOCIAL_COMMERCE_CARD

A feed-oriented 3:4, 4:5, 9:16, square, or editorial card. It may use collage or lifestyle grammar but must remain an ecommerce selling visual rather than an article screenshot.

### MARKETING_VISUAL_SET

A mixed benchmark set containing two or more legitimate delivery formats. Create a campaign passport, then adapt composition separately for each canvas. Never resize one master layout into every format.

## Decision rules

1. Use commercial job, reading behavior, and sequence before aspect ratio.
2. If one board contains several formats, segment first and group units by route.
3. Match the benchmark's broad delivery form unless the user names another output.
4. Infer image count from distinct buyer jobs and usable benchmark units; do not default to six images or eight screens.
5. Preserve one campaign identity across a set, but rebuild geometry for every target canvas.
6. When platform specifications are not supplied or currently verified, create review masters at the benchmark ratio and label backend-specific export dimensions as configurable.
