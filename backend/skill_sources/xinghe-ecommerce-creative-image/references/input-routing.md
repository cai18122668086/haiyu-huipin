# Input Routing

## 产品图 Only

先分析可见事实，再生成点击钩子：

- 可见事实：品类、形态、颜色、包装、结构、材质、SKU、可见文字、规格线索。
- 不可见信息：不要写成确定事实；需要时写成通用场景。
- 点击方向：优先提炼用户购买前的真实阻力，例如不方便、不好搭、不知道怎么选、看不出质感、担心踩雷。
- 画面方式：产品放大，标题前置，痛点可视化，标签不超过 3 个。

## 产品图 + 文案 / 卖点

用户内容优先：

- 保留核心卖点，不改掉意思。
- 长文案压缩成：1 个强标题 + 最多 3 个短标签 + 1 个画面利益点。
- 如果用户文案低点击，改写为更短、更有问题感或结果感的表达。
- 不补充用户没提供且无法从图片看出的夸张功效。

## 产品图 + 数量要求

- 默认 1 张。
- 用户指定 N 张时，每张应有不同点击角度，避免只换背景。
- 多图常用分化：痛点型、场景型、对比型、结果型、人群型。

## 产品图缺失

如果用户要做具体商品图但没有产品图，先要求上传产品图。不要生成会误导产品外观的广告图。
