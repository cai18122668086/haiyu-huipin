# Compliance And QC

## 高风险品类

食品、保健、美妆功效、母婴、儿童安全、医疗相关产品要保守。

不要写：

- 治疗、改善疾病、降糖、降压、减肥、排毒、药用功效。
- 绝对化表达：最强、第一、100%、永久、根治。
- 虚构证明：销量、评价、认证、检测、授权、实验报告编号。
- 未经用户提供的品牌背书、明星同款、大牌同厂。

可以写：

- 包装可见信息。
- 通用使用场景。
- 用户明确提供且合规的卖点。
- 低风险体验表达，例如便携、易收纳、适合早餐场景。

## 出图后快速检查

- 3 秒测试：看懂卖什么、解决什么问题、为什么想点。
- 缩略图测试：产品和标题在手机尺寸仍清楚。
- 产品保真：颜色、结构、包装、logo、关键细节不跑偏。
- 文案可读：没有乱码、小字堆叠、过多标签。
- 合规检查：没有虚构销量、评价、认证、检测、绝对功效。

## 失败重生成规则

出现以下情况，要建议或执行重生成：

- 产品变形、包装错字、logo 失真。
- 标题乱码、太小或被产品遮挡。
- 产品占比过小，第一眼看不出卖什么。
- 画面好看但点击钩子弱。
- 出现假认证、假销量、假评价、假授权。
- 竞品参考被照搬得太像。
