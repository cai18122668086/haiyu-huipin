# Competitor Analysis

有竞品参考图时，先拆解再生成原创图。

## 必须分析

- 文案钩子：为什么让人想点，是问题、痛点、利益、反差还是人群？
- 排版层级：第一眼、第二眼、第三眼分别看什么？
- 构图机制：产品占比、主体角度、场景、对比、局部放大、人物动作。
- 高点击点：痛点可视化、强结果感、视觉反差、信任符号、场景代入。

## 保留

- 有效点击逻辑。
- 清晰的信息层级。
- 让用户停留的痛点表达方式。
- 适合该品类的构图机制。

## 避开

- 原图文案逐字照搬。
- 原品牌、商标、认证、销量、评价。
- 相同版式细节、贴纸样式、图形资产。
- 相同人物姿势或可识别素材。

## 转化方式

把竞品的“为什么能点”转成用户产品的原创表达：

- 同样是痛点，但换成用户产品真实可承载的痛点。
- 同样是对比，但不虚构前后效果。
- 同样是标签，但改成用户产品可见或已提供卖点。
