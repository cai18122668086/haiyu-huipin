# Platform Strategies

按用户指定平台加载；未指定时使用通用电商主图策略。

## 通用电商主图

- 比例：1:1。
- 产品大、标题大、标签少。
- 适合：淘宝、拼多多、1688、私域货盘、信息流商品卡。

## 淘宝 / 天猫

- 重点：品质感、清楚卖点、可信表达。
- 文案：少而准，避免低质促销感。
- 画面：产品摄影质感强，留出标题安全区。

## 拼多多

- 重点：强利益、强对比、快速看懂。
- 文案：更直接，但不虚构价格、销量、补贴。
- 画面：产品占比高，利益标签更醒目。

## 抖音 / 快手

- 重点：痛点冲突、场景代入、短时间停留。
- 文案：问题型、反差型、结果型优先。
- 画面：可加入人物手部、使用瞬间、前后状态对比，但不虚构功效。

## 小红书

- 重点：生活方式、真实种草、审美可信。
- 文案：像真实用户会停下看的问题，不要太硬广。
- 画面：场景感、质感、细节局部更重要。

## 亚马逊 / 跨境

- 重点：清楚、可信、少文字、产品功能可视化。
- 文案：英文短句或图标标签，避免夸张促销。
- 画面：干净背景、功能 callout、使用场景。

## 尺寸比例

- 默认：1:1。
- 竖版信息流：4:5 或 9:16。
- 横版广告：16:9。
- 用户给定尺寸时优先用户要求。
